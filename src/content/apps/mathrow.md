MathRow — Cross Sums Puzzle is a clean, offline logic puzzle game where you solve grid-based challenges by selecting numbers that correctly match row and column sums.

Train your brain with simple rules but deeply challenging gameplay. Every level is procedurally generated, meaning you’ll never run out of puzzles to solve.

🧩 Gameplay

Each puzzle consists of a grid of numbers with target sums shown on the edges. Your goal is to decide which numbers to keep and which to remove so that:

Each row matches its target sum
Each column matches its target sum

A single mistake costs a life, so think carefully before each move.

✨ Features
🎯 3 Difficulty Levels — Easy (4×4), Medium (5×5), Hard (6×6)
♾️ Infinite Puzzles — procedurally generated with unique solutions
❤️ 3-Lives System — mistakes are punished but help you learn
💡 1 Hint Per Level — get help when stuck
✎ Two Play Modes — Circle or Erase cells
🌙 Dark Mode Support — fully themed UI
🌍 Multilanguage Support — English, O‘zbek, Русский
📊 Progress Tracking — saves your best level per difficulty
⚙️ Offline Gameplay — no internet required
🧠 Why You’ll Like It

MathRow is designed to improve logical thinking, focus, and pattern recognition. It’s simple to learn but becomes deeply strategic as difficulty increases.

Perfect for short sessions or long puzzle-solving streaks.

📱 Technical Highlights
Built with Kotlin + Jetpack Compose (Material 3)
MVVM architecture with StateFlow
Local persistence via DataStore
Fully offline — no ads, no tracking
